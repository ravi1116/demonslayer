Install Tomcat
Open Eclipse

Create:

Dynamic Web Project
Add Tomcat server:
Window → Show View → Servers
Right click → New → Server
Select Apache Tomcat

Put home.jsp inside:

WebContent

or

src/main/webapp

Run:

Right Click Project → Run As → Run on Server

Then browser opens like:

http://localhost:8080/ProjectName/home.jsp
